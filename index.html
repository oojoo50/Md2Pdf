Frequently asked questions

Is Md2Pdf really free?

Yes — there is no account, no watermark and no usage limit.

Are my Markdown files uploaded anywhere?

No. Parsing, rendering and PDF creation all run locally in your tab.

Which Markdown syntax is supported?

GFM tables, task lists, footnotes, code highlighting, LaTeX math and Mermaid diagrams.

English, Korean, Hindi, Japanese and Simplified Chinese.
